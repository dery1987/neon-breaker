NEON BREAKER is a neon arcade breakout game: slide the glowing paddle, smash every brick, catch falling power-ups (wide paddle, multi-ball, slow ball, extra life), and clear all 5 levels to win. Combo multipliers reward long rallies, particles and screen shake juice up every break, and all sound effects are synthesized live with WebAudio — no files, no network, just open and play.

## Run it

```sh
node serve.ts
```
